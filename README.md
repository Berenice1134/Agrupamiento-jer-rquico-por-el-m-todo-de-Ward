# Agrupamiento-jer-rquico-por-el-m-todo-de-Ward
 El metodo de Ward es una tecnica de clustering jerarquico diseñada para minimizar la varianza dentro de losclusters.
 En cada paso, el metodo fusiona los pares de clusters que resultan en el menor incremento posible en la suma total de las distancias cuadradas dentro de los clusters, evaluando c´omo la combinacion de clusters afecta la dispersion interna en comparacion con sus centroides originales.
